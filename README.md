# 大肥鱼心境

四个激素，各 0~1，随时间回到基线（半衰期约 34.7 小时），被对话事件扰动，
然后把"此刻的心境"写进提示词——**她说话的语气会跟着变**。

| 激素 | 基线 | 管什么 |
|---|---|---|
| 血清素 sero | 0.60 | 耐心、包容 |
| 多巴胺 dopa | 0.40 | 主动、活泼 |
| 皮质醇 cort | 0.20 | 压力（高会压抑记忆召回、压低技能发挥） |
| 催产素 oxy | 0.50 | 依恋、亲近 |

## 事件

- 正向（想你/抱/谢谢）→ 催产素、多巴胺↑，压力↓
- 负面（烦/滚/失望）→ 压力↑，血清素↓，催产素↓（有依恋惯性，吵一次不会清零）
- 治愈（难过/累/失眠）→ 血清素、催产素↑，压力↓

## 命令

| 命令 | 作用 |
|---|---|
| `/心境` | 看四激素与派生量 |
| `/心境重置` | 回基线 |

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enable` | true | 开关 |
| `inject` | true | 自己写提示词（交给 mindcore 时关掉） |
| `gate_proactive` | true | 心情差时压掉主动消息 |
| `gate_cort` | 0.45 | 压制阈值 |

## 派生的三个量

- `f_endo`：记忆召回加权（心情好更愿意提旧事）
- `Qmax`：压力大时技能发挥上限
- `bonus`：陪伴类技能依恋加成
